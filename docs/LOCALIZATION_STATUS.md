# Localization status

The app's language selector now recognizes English, Persian, Simplified Chinese,
Arabic and Turkish. Arabic and Turkish have reviewed translations for core
navigation, connection state, settings and gaming labels; long-tail strings still
fall back to English until reviewed translations are added. This is not yet a
claim of complete five-language localization.

RTL layout validation for Arabic and Persian, plural/number/date formatting,
accessibility labels, notifications, widgets and all dialogs remain acceptance
items. Do not claim full RTL compliance until tested on real Android API levels.
